Point de repère / Registres

Les cases de travail du processeur.

Dans le processeur, un registre conserve une donnée, une adresse ou un état.

EAX

Valeur de travail ou résultat d’un appel.

EIP

L’adresse de l’instruction à exécuter.

ESP

L’adresse du sommet de la Stack.

Lecture d’une instruction · x86, 32 bits

mov eax, [esp]

1. Lire l’adresse contenue dans ESP.

2. Lire les 4 octets en mémoire à cette adresse.

3. Placer cette valeur dans EAX.

Les crochets signifient « accéder à la mémoire ».

Un registre peut contenir une adresse. La donnée pointée reste en mémoire.

Point de repère / La Stack en mouvement

Appeler, c’est aussi préparer le retour.

Sur x86, empiler 4 octets diminue ESP de 4. Ici, les adresses diminuent vers le bas.

1. Un argument empilé

0x1000…
0x0FFC42 ← ESP
0x0FF8libre

push 42

Le sommet pointe sur l’argument.

2. L’appel

0x1000…
0x0FFC42
0x0FF8retour ← ESP

call fonction

L’adresse de l’instruction suivante est empilée ; l’exécution saute dans la fonction.

3. Le retour

0x1000…
0x0FFC42 ← ESP
0x0FF8libérée

ret sans opérande

L’adresse de retour est dépilée. L’argument reste à retirer selon la convention.

La Stack est une zone de mémoire ; ESP indique où nous en sommes.

Appeler / Partager les mêmes règles

Une bonne adresse ne suffit pas.

Application Binary Interface (ABI) : contrat binaire, dont les règles d’appel entre fonctions.

Exemple : appel Windows 32 bits, __stdcall

[ESP]adresse de retour
[ESP + 4]premier argument
[ESP + 8]deuxième argument
EAXrésultat entier simple

Les deux côtés doivent s’accorder.

Argumentsordre et emplacement
Registreslesquels préserver
Stackalignement et nettoyage

Avec __stdcall, la fonction appelée retire ses arguments. Avec __cdecl, l’appelant le fait.

La Stack respecte les règles d’appel. Le programme attend aussi son identité Windows.

Autre mécanisme / Une porte d’entrée générée

Un thunk : 15 octets pour passer la main.

Un petit adaptateur de code indique quel service traiter au dispatcher, le répartiteur commun des appels.

Version 32 bits réellement générée

155211

Windows New Technology (NT) désigne ici la famille de services Windows bas niveau.

Ce numéro sélectionne un handler interne ; il ne devient pas un numéro d’appel système Linux.

push ebpPréserver un registre.
mov eax, adresseOù est le dispatcher ?
mov edx, numéroQuel service traiter ?
call eaxEntrer dans le dispatcher.
pop ebpRestaurer le registre.
retRevenir à l’appelant.

Le thunk transfère au dispatcher. Comment celui-ci travaille-t-il, puis retrouve-t-il l’appelant ?

Frontières / Ce que le pont garantit vraiment

Chaque passage a ses conditions.

01 / Services

Un appel Windows ne se transmet pas brut.

Numéro, arguments, objets et erreurs dépendent du système. Les instructions d’appel système arbitraires ne sont pas toutes interceptées.

02 / Contexte

Appeler une bibliothèque Linux demande un état adapté.

Les ponts du projet gèrent Stack et segments selon l’architecture. La bibliothèque standard C, libc, n’est pas automatiquement inutilisable dans tout code invité.

03 / Erreurs

Linux reçoit d’abord les fautes du processeur.

Une Stack de signal alternative aide au diagnostic. La traduction complète vers les exceptions Windows reste inachevée.
